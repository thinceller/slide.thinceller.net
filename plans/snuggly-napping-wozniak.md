# Index ページ リデザイン計画

## 概要

Gaia leadクラスの視覚的特徴とthinceller.netのミニマリズムを融合した新しいindexページデザインを実装する。**ライトテーマのみ**。

**コンセプト**: 「Minimal Centered Light」

## Gaia leadクラスの特徴（ライト）

- センター配置のコンテンツ
- 大きく印象的なタイポグラフィ
- 薄い色の背景（cornsilk #fff8e1 など）
- タイトルスライド向けのヒーロー的レイアウト

## thinceller.net の特徴

- ミニマリスト、機能的
- 白背景
- システムフォント
- 余白重視、max-width制約
- シンプルなホバー効果（ボーダー色変更）

## デザイン方針

| 要素 | Gaia lead から | thinceller.net から |
|------|----------------|---------------------|
| レイアウト | センター配置ヒーロー | max-width制約、余白重視 |
| タイポグラフィ | 大きなタイトル | システムフォント |
| 背景 | - | 白背景 |
| インタラクション | - | シンプルなホバー |

## 変更前後の比較

| 要素 | 現在 | 変更後 |
|------|------|--------|
| フォント | Google Fonts (DM Sans, Playfair Display) | システムフォント |
| 背景色 | 薄い黄色（#fff8e1） | 白（#ffffff） |
| ヒーロー | 左寄せヘッダー | **センター配置**、大きなタイトル |
| カード背景 | 白 | gray-50（#f9fafb） |
| カード丸み | 16px | 8px（控えめ） |
| ホバー | 浮き上がり + 影 | **ボーダー色変更のみ**（シンプル） |
| アニメーション | fadeUp 24px | fadeIn 12px（控えめ） |

## カラーパレット

```css
:root {
  /* 背景 */
  --color-bg: #ffffff;              /* 白（thinceller.net風） */
  --color-bg-secondary: #f9fafb;    /* gray-50（カード背景） */

  /* テキスト */
  --color-text: #111827;            /* gray-900 */
  --color-text-muted: #6b7280;      /* gray-500 */

  /* ボーダー */
  --color-border: #e5e7eb;          /* gray-200 */

  /* アクセント */
  --color-accent: #2563eb;          /* blue-600 */
  --color-accent-hover: #1d4ed8;    /* blue-700 */
}
```

## 実装ステップ

### 1. CSS変数とカラーパレット定義
- `:root` にカラー変数を定義
- 白背景ベース + gray系テキスト + blue-600アクセント

### 2. ヒーローセクション実装（Gaia lead風）
- センター配置
- 大きなタイトル（clamp使用でレスポンシブ）
- システムフォント
- 十分な余白（padding）

### 3. カードコンポーネント更新（thinceller.net風）
- グリッドレイアウト維持
- 背景: gray-50
- border-radius: 8pxに縮小
- ホバー: ボーダー色変更のみ（シンプル、浮き上がりなし）
- アニメーション: 控えめに（12px移動）

### 4. レスポンシブ調整
- モバイル向けスペーシング調整
- 矢印アイコンは640px以下で非表示

### 5. frontend-design スキルでの実装
- 上記設計に基づいてfrontend-designスキルを使用
- 高品質なデザイン実装

### 6. code-simplifier による改善
- 実装完了後にcode-simplifierで最適化

### 7. 動作確認
- `pnpm build` でビルド実行
- `pnpm dev` でローカル確認

## 対象ファイル

- `scripts/generate-index.js` - HTML/CSS生成スクリプト（メイン変更対象）

## 検証方法

1. `pnpm build` が正常に完了すること
2. `pnpm dev` でローカルサーバー起動し http://localhost:8787 でindexページ確認
3. ヒーローがセンター配置で表示されること
4. スライドカードのホバー効果が動作すること（ボーダー色変更）
5. モバイル表示でレスポンシブが適用されること
